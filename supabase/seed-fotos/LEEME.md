# Fotos del escenario demo

Coloca aquí seis fotos en formato JPG, con estos nombres exactos:

| Archivo | Especie |
| --- | --- |
| `sierra.jpg` | Sierra |
| `huachinango.jpg` | Huachinango |
| `cabrilla.jpg` | Cabrilla |
| `pargo.jpg` | Pargo |
| `corvina.jpg` | Corvina |
| `lenguado.jpg` | Lenguado |

- Usa fotos propias o con licencia libre (por ejemplo CC0) y anota la fuente aquí abajo.
- Tamaño recomendado: 1280 px de ancho, menos de 400 KB.
- `scripts/crear-usuarios-demo.mjs` las sube al bucket `capturas` como `demo/<especie>.jpg`.
